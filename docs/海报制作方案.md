# 车车多多 · 海报制作方案

> 适用对象：微信小程序「车车多多」上线宣发
> 视觉方向：Apple 极简风（延续小程序设计系统）
> 版本：v1.0 初稿 —— 待接入小程序码后定稿

---

## 0. 一句话总结

一套 Apple 极简视觉，双版本复用：

- **线上竖版 9:16**（朋友圈 / 微信群转发）
- **线下横版 A4**（校园公告栏张贴）

核心信息 = 痛点标题 + 三大卖点 + 小程序码，让同学「3 秒扫完、扫码即走」。

---

## 1. 宣发目标与策略

| 项 | 内容 |
|---|---|
| 宣发目标 | 拉新：让目标学生**首次扫码进入小程序**，并完成一次行程浏览 |
| 目标受众 | 高校学生（日常通勤、周末返乡、节假日出行） |
| 核心卖点 | 同校实名拼车 · 省钱（平摊车费）· 省时（一键成团） |
| 行动号召 CTA | **扫码进入小程序**（单一动作，不贪多） |
| 转化路径 | 看到海报 → 扫码 → 进入行程广场 → 浏览 / 发布第一段行程 |

## 2. 文案方案（信息架构）

海报阅读顺序从上到下，与文案优先级一致：

**① 主标题（3 选 1）**

| 方案 | 文案 | 适用 |
|---|---|---|
| ✅ 推荐 | **「一个人打车太贵，车车多多刚刚好」** | 痛点 + 方案，最口语，像同学之间说话 |
| 备选 A | 「同一条路，拼着走更省」 | 简洁，偏理性 |
| 备选 B | 「把回家的路，拼给同路人」 | 偏情怀，适合节假日返乡节点 |

**② 副标题**

> 同校实名拼车 · 一键发布 · 随时加入

**③ 三大功能亮点（三张小卡片）**

- 🛡️ **同校实名** —— 只和校友同行，更安心
- 💰 **平摊车费** —— 人均省一半，看得见
- ⚡ **一键成团** —— 发布即开拼，随点随走

**④ CTA**

> 微信扫码 · 马上出发

**⑤ 品牌落款**

> 🚗 车车多多 · 让每一次出行都有人同行

> ⚠️ 文案红线：不承诺未经确认的具体折扣数字（如需写「省钱 xx%」先与产品侧核对）；不写「免费」除非真有补贴活动。

## 4. 视觉方案（Apple 极简风）

延续小程序既有设计语言 —— 用户看到海报 = 看到产品，强化认知一致性。

### 色板

| 用途 | 色值 |
|---|---|
| 背景 | `#f5f5f7`（可加 `#fbfbfd → #f0f2f5` 微渐变） |
| 主色（品牌蓝） | `#007aff` |
| 主文字 | `#1d1d1f` |
| 次要文字 | `#86868b` |
| 卡片 | `#ffffff` + 阴影 `0 8px 16px rgba(29,29,31,.07)` |
| 落款文字 | `#a1a1a6` |

### 字体

PingFang SC / SF Pro / Helvetica Neue（系统字体，无版权风险）

- 主标题：竖版 96px、700 字重
- 副标题 / 卖点：40px 常规
- 落款：28–30px `#a1a1a6`

### 构图

大留白 + 居中偏上的标题区 + **一条「起点 → 终点」虚线路线**做主视觉 + 三张白色圆角卡片 + 底部二维码区。信息密度控制在「3 秒扫完」。

### 主视觉元素

虚线路线 + 小汽车 + 起点 / 终点标注（🏫 学校 → 🚉 车站/机场）—— 一张图讲清产品是干嘛的。

## 5. 素材清单（含小程序码留位规范）

| 素材 | 状态 | 说明 |
|---|---|---|
| 小程序码 | ⏳ **待你提供** | 小程序后台「生成小程序码」获取；建议**为每个渠道单独生成**（带不同 scene 参数）以便统计来源 |
| Logo | 暂用文字 logo | 蓝色圆角方块 + 🚗 + 「车车多多」；后续可升级正式图标（建议 1024×1024 圆角方形） |
| 手机截图 | 待补 | 用微信开发者工具模拟器截图「行程广场」页，2x 高清，用于后续丰富版面 |
| 字体 | ✅ 系统字体 | 无版权风险 |

### 小程序码留位规范（保证可扫）

- 尺寸：竖版 ≥ 340px（约版面 1/3 宽）；打印版 ≥ 4×4cm
- 白底圆角，码四周留白 ≥ 码宽 1/10
- 不要压暗、加投影、覆盖定位角；与背景对比度 ≥ 3:1
- 离折痕 / 裁切边 ≥ 1.5cm

## 6. 制作流程与工具

本方案已附**代码版 SVG 初稿**（`docs/posters/`），浏览器直接打开即可预览、截图导出 PNG，可直接作为交付物，也可作为 Figma / 稿定设计精修的底稿。

| 时间 | 事项 |
|---|---|
| D0（今天） | 定文案（第 2 节 3 选 1）→ 出竖版初稿 |
| D1 | 你提供小程序码 → 替换占位，导出竖版 PNG |
| D2 | 出横版 + 校对（标题、错别字、码可扫） |
| D3 | 交付：竖版 1080×1920 PNG + 横版 3508×2480 PNG + SVG 源文件 |

工具备选：**本方案 SVG**（免费、改代码即改图）/ **Figma**（精细控制）/ **稿定设计、Canva**（套模板最快）。

## 7. 投放计划

### 线上（周五 – 周日窗口）

- 周五下午–晚上：朋友圈（配一句推荐语）+ 班群 / 宿舍群 / 老乡群 / 校园集市群
- 3 天后换 B 文案再做一轮，对比两版扫码量（A/B 测试）
- 渠道统计：朋友圈、各群分别生成**不同 scene 的小程序码**，后台看打开数据

### 线下（周五中午前贴完，赶上周末返乡高峰）

- A4 横版打印 30–50 张：宿舍楼公告栏、食堂、教学楼大厅、校门口、快递站
- 建议底部加 **3–5 张撕拉条小程序码小条**，扫码率更高（需在版面底部留撕拉区）

### 拉新钩子（可选，需产品配合）

首次发布行程送券 / 邀请 1 位好友得权益 —— 海报 CTA 区可加一行小字。
